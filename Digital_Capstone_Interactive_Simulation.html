Digital Electronics Capstone — Interactive Simulation

Standalone browser demonstration of the MOD-6 synchronous counter and two-road Moore traffic-light controller. This is a learning simulation, not a Logisim project file.

1. MOD-6 synchronous counter

Sequence: 000 → 001 → 010 → 011 → 100 → 101 → 000

Current output: 000 (decimal 0)

Invalid states 110 and 111 recover to 000 on the next clock pulse.

2. Two-road traffic-light Moore FSM

State sequence: S0 → S1 → S2 → S3 → S4 → S5 → S0

Current state: S0 (000)

Road B

S2 and S5 are all-red clearance states. In a real controller, use a clock divider/timer to set safe real-world signal durations.
