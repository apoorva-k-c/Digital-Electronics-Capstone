# Digital Electronics Capstone Project

## Project Overview

This repository contains two digital electronics designs developed as part of the TiEdu Digital Electronics Capstone Project.

The project demonstrates the application of finite state machines, synchronous counters, Boolean logic and digital circuit design.

## Project Designs

### 1. Two-Road Traffic Light Controller

- Designed using a Moore Finite State Machine (FSM).
- Controls traffic signals for two intersecting roads.
- Uses defined states to manage the traffic-light sequence.
- Includes state transition logic and design documentation.

### 2. MOD-6 Synchronous Counter

- Designed as a synchronous counter with six states.
- Counts from 0 to 5 and then returns to 0.
- Uses flip-flop-based counter design principles.
- Includes Boolean logic and design documentation.

## Technologies and Tools

- Logisim Evolution – Digital logic design
- Verilog HDL – Hardware description
- HTML, CSS and JavaScript – Interactive demonstration

## Learning Outcomes

Through this project, the following concepts were explored:

- Moore FSM design
- State transition tables
- Boolean expressions and Karnaugh maps
- Synchronous counter design
- Digital logic implementation
- Verilog HDL fundamentals
